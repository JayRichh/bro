# 0.52: trust what you see

0.49–0.51 shipped a lot of UI that has only been tested in units, draw tests and a demo bridge. 0.52 proves the
flows end to end on Windows, makes attribution exact, and teaches the new UI in place.

## Goals
1. **End-to-end proof on Windows.** The real `kete` binaries, isolated data dirs, a scripted fake agent, the TUI
   driven through a real ConPTY: start → running → needs you → review → ship (against a local bare "forge") →
   done, scope chip, `?` verbs, drag on the board, paste. Same flows in the desktop via its Tauri test harness or
   the demo bridge wired to a real daemon.
2. **Exact attribution.** Snapshot at the start and end of every turn; a session's changes are the union of its
   own turns, so concurrent sessions in one worktree no longer bleed into each other.
3. **Learn in place.** First-use hints for `?`, the scope chip, the Review/Ship lanes and drag; a "What's new in
   0.49–0.52" page in both apps; every empty state says what to do next.
4. **Loose ends.** `kete ship` uses the recorded base; a safe sweep for orphaned `refs/kete/sessions/*` refs owned
   by this daemon's data dir; faster daemon-side paste write into the agent's ConPTY.

## Deliverables
- `lane/e2e-windows`: a Windows e2e harness (portable-pty) next to the unix `e2e_tui.rs`, a fake harness agent
  binary/script that can be told to run, ask for input, edit files, commit and finish; tests for the flows above;
  runs in CI on windows-latest. Fix what it finds.
- `lane/turn-attribution`: per-turn snapshots (turn start = status → running after a prompt; turn end = finished /
  needs feedback); session changes = combined diff of its turns; review filter unchanged; refs per turn pruned to
  start/end pairs; orphan-ref sweep keyed by a daemon id written into the ref namespace.
- `lane/learn`: hints (dismissible, remembered per user, off switch in Settings), What's new page, empty states,
  both apps; registry-driven so hints name the user's actual keys.
- `lane/loose-ends`: `kete ship` reads `WorktreeBases`; daemon paste write throughput (chunking, fewer syscalls)
  with a measured before/after.

## Release
- 0.52.0 when the lanes land; the Windows e2e suite joins the CI gate.
